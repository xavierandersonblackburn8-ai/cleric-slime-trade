# Cleric Slime Trade 1.3.0

Minecraft 26.3 / Fabric / Java 25. Preserves 1.2.1 trade data. Adds a Mixin intended to double the vanilla player XP orb payout for the two slime trades only.

Build using the GitHub Actions **Build Fabric JAR** workflow. Do not install an artifact until the workflow has compiled successfully and the Mixin target has been verified in game.
